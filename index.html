Arduino LED Blinking Experiment

Live Simulation

Theory

This experiment demonstrates how to control an LED using an Arduino board. The **LED_BUILTIN** refers to the onboard LED of the Arduino, which is typically connected to **pin 13**.

Working Principle

  • In the **setup()** function, pin 13 is set as an output using pinMode().
  • The **loop()** function continuously turns the LED on and off.
  • digitalWrite(LED_BUILTIN, HIGH) turns the LED on.
  • A **delay of 1 second** is added to keep the LED on.
  • digitalWrite(LED_BUILTIN, LOW) turns the LED off.
  • Another **1-second delay** ensures a visible blinking effect.

Code Explanation

void setup() {
    pinMode(LED_BUILTIN, OUTPUT); // Set LED pin as output
}

void loop() {
    digitalWrite(LED_BUILTIN, HIGH); // Turn LED ON
    delay(1000);                     // Wait for 1 second
    digitalWrite(LED_BUILTIN, LOW);  // Turn LED OFF
    delay(1000);                     // Wait for 1 second
}

Applications

- Used in **traffic signals**, **indicator lights**, and **status LEDs**.
- Helps beginners understand **basic microcontroller programming**.
- Forms the foundation for more advanced **embedded systems projects**.
